# 一个基于案例正负面表现的带权评估方法
## 背景
最开始的应用想法是想出一个归一化的指标，来判断一个人在交易上是否值得信任，后来发现该函数还可以扩展成为其他评估方法（如技能熟练度、改善趋势等），因此记录一下这个想法[^1]

## 指标定义
设 \\( \lbrace x_i \vert x_i \in \lbrace 0, 1 \rbrace \rbrace, i = 1, 2, ..., n ， n \in Z^+ \\) 表示依次发生的 \\( n \\) 个案例，其中 \\( x_i = 0 \\) 表示第 \\( i\\) 个案例表示反面，\\( x_i = 1 \\) 表示第 \\( i \\) 个案例表现正面，\\( \lbrace w_i \vert w_i \in Z^+ \\) 表示第 \\( i \\) 事件对应的评估权重，定义该系列事件的整体评估指标为：
\\[
    (\frac{\sum_{i=1}^{n} x_i}{n})^{\frac{\sum_{i=1}^{n} w_i}{\sum_{i=1}^{n} x_iw_i + 1}} \times 100 \%
\\]

### 性质
#### 一诺千金与“满嘴跑火车”
显然，如果一系列案例均为正面表现，则该指标为 100%；而如果一系列案例均为负面，则该指标为 0%

#### 奖惩敏感
指标会根据新事件的权重以及而对其产生剧烈影响，并且该影响会累计到指标中。

## 存在问题
任何指标最大的问题，是标准的指定存在片面性与执行记录的可选择性，仅能参考而无法产生详细的作用。
